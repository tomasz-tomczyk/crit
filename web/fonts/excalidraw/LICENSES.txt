Fonts for Excalidraw scenes (web/crit-renderer-excalidraw.js)

Byte-for-byte copies of packages/excalidraw/fonts/<Family>/*.woff2 in
https://github.com/excalidraw/excalidraw at commit b7de45e8 (2026-10-23),
in the same <Family>/ layout. SHA256SUMS lists each file; a unit test
(web/__tests__/crit-renderer-excalidraw.test.js) checks them.

Not included: Liberation Sans (Excalidraw font 9; these outlines are not
OFL-licensed, and Arial / Helvetica have the same metrics), Assistant
(Excalidraw's UI font) and the fallbacks Xiaolai (CJK) and Segoe UI Emoji.
Helvetica (font 2) is a system font in Excalidraw too.
